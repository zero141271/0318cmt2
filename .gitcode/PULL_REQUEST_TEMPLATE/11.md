**Self CheckList** :

> PR提交人对以下CheckList自检项进行全量自检，自检通过或不涉及，均修改 [ ] 为 [x]

- [ ] PR标题和描述，是否按格式填写
- [ ] 代码注释是否完备，是否正确记录错误日志
- [ ] 若涉及对外接口变更，是否已通过变更评审，是否考虑兼容性影响
- [ ] 是否通过本地IDE对代码进行静态检查、格式化处理
- [ ] 是否进行空指针校验
- [ ] 是否进行返回值校验 (禁止使用void屏蔽安全函数、自研函数返回值，C++标准库函数确认无问题可以屏蔽)
- [ ] 若存在资源申请，使用后是否正确释放
- [ ] 若涉及多线程场景，是否考虑并发和死锁
- [ ] 是否充分考虑接口的异常场景
- [ ] 新增或修改的代码是否完成DT测试，且测试覆盖率达到标准要求

**Committer CheckList** :

> Committer 对以下CheckList项进行全量检视，通过或不涉及，均修改 [ ] 为 [x]

- [ ] PR功能单一，超500行代码上库前需要集体检视，超1000行代码需要拆分PR
- [ ] PR中的有效检视意见，是否均已修改完成，Reviewer/Committer已回复ok
- [ ] 测试用例覆盖场景是否完备，自测试报告是否完整
- [ ] 是否选择正确的上库分支
- [ ] PR加分是否满足要求
- [ ] 若涉及对外接口变更，是否已通过变更评审，是否考虑兼容性影响
- [ ] 是否进行返回值校验 (禁止使用void屏蔽安全函数、自研函数返回值，C++标准库函数确认无问题可以屏蔽)
- [ ] 若存在资源申请，使用后是否正确释放
- [ ] 若涉及多线程场景，是否考虑并发和死锁
- [ ] DT增量行覆盖率要求80%
